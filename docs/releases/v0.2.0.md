# Ler sem Barreiras v0.2.0

**Data:** 18 de novembro de 2026  
**Tipo:** nova linha de desenvolvimento (não é um APK substituto da v0.1.1-beta)

## Sumário

A versão **0.2.0** documenta e inicia a **reescrita em React Native**. A aplicação Kotlin/Android nativa (0.1.x) não está a funcionar correctamente no contexto escolar e deixa de ser a base activa do produto móvel.

O código da app móvel vive em [`mobile/`](../../mobile). Ainda **não** há uma Release GitHub com APK React Native para a sala de aula. A última app Kotlin instalável continua a ser a [v0.1.1-beta](https://github.com/HXB-Informatica/ler-sem-barreiras/releases/tag/v0.1.1-beta).

## Motivação

- Falhas e fragilidade da cadeia nativa (gravação, JNI/whisper.cpp, alinhamento no equipamento alvo).
- Validação no HOTWAV TAB R9 Plus nunca concluída na linha 0.1.
- Ferramenta e linguagem pouco acessíveis para quem vai manter o projecto na escola.
- O produto (offline, professor/aluno, `.lsb`) permanece; muda a implementação da UI e da app móvel.

A decisão completa está em [docs/adr/0001-migrar-para-react-native.md](../adr/0001-migrar-para-react-native.md).

## O que esta versão inclui

- ADR 0001 aceite: React Native para a app móvel.
- App TypeScript em `mobile/` (React Native 0.88): ecrãs Professor/Aluno, persistência local, importação `.lsb`, gravação WAV PCM 16 kHz.
- Alinhador portado (tokenizer, Needleman–Wunsch, lacunas curtas, validador) com testes Jest.
- Módulos nativos Android: ficheiros, ZIP seguro, áudio; ponte Whisper com o mesmo contrato, ainda sem whisper.cpp compilado.
- Kotlin 0.1.x congelado como referência de formatos e Studio Windows.

## O que esta versão não inclui

- whisper.cpp ligado ao APK React Native (a sincronização automática no tablet recusa com mensagem clara).
- Editor visual de intervalos com forma de onda.
- APK assinado para a sala de aula / Release GitHub desta linha.
- Reescrita do Studio Windows.
- Alteração de licença, princípios offline ou formato `.lsb`.

## Próximo passo técnico

1. Ligar whisper.cpp ao `LsbSpeechModule` e empacotar `ggml-tiny.bin` na compilação.
2. Completar o editor de intervalos.
3. Gerar APK de testes e validar o ciclo completo no HOTWAV TAB R9 Plus em modo avião.
